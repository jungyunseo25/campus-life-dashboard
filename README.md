# 🎓 학과별 학생 생활습관 및 만족도 분석 앱 (Student Lifestyle & Satisfaction Dashboard)

대학교 1학년 비전공자 학생들이 파이썬과 Streamlit을 활용해 제작한 데이터 분석 웹 애플리케이션입니다. 학생들의 생활습관(공부시간, 수면시간, 스마트폰 사용시간, 통학시간)과 학교생활 만족도 간의 관계를 분석하고, 한 줄 의견에 대한 텍스트 빈도 및 긍정/부정 경향을 시각화합니다.

---

## 🚀 주요 기능 (Features)
1. **CSV 파일 업로드 및 데이터 미리보기**: 분석하고자 하는 학생 설문 데이터를 업로드하고 원본 데이터를 표로 확인할 수 있습니다.
2. **오류 데이터 전처리 및 예외 처리**: 
   - 숫자가 아닌 문자열이나 비정상적인 데이터(결측치, 음수 시간 등)를 자동으로 감지하고 제외합니다.
   - 제외된 오류 데이터의 총 건수를 화면에 투명하게 표시합니다.
3. **학과별 필터링 기능**: 
   - 전체 학생 또는 특정 학과를 선택하여 맞춤형 분석 결과를 확인할 수 있습니다.
   - 선택한 학과의 평균 학교생활 만족도를 실시간 지표(Metric)로 제공합니다.
4. **시각화 그래프**:
   - **산점도(Scatter Plot)**: 공부시간과 학교생활 만족도 간의 관계 분석
   - **막대그래프(Bar Chart)**: 주요 생활습관 항목별 평균 시간 비교
   - **텍스트 분석 (Top 10 핵심 단어)**: 한 줄 의견에서 가장 많이 등장한 상위 10개 단어 빈도 막대그래프
   - **긍정/부정 키워드 분석**: 주요 감성 키워드 등장 횟수 비교 (Metric 표시)

---

## 🛠️ 사용 기술 스택 (Tech Stack)
* **Language**: Python 3.x
* **Web Framework**: Streamlit
* **Data Analysis**: Pandas, NumPy
* **Visualization**: Matplotlib, Seaborn
